# 全日期时间线设计

## 目标

取消页面日期选择器。页面自动读取所有可用日期，把三个活动领域的文章合并为一条时间线，并按文章日期从新到旧展示。

## 数据流

1. 页面加载 `/api/domains` 和 `/api/dates`；日期列表只接受有效的 `YYYY-MM-DD`，并先按降序排列。
2. 对每个日期和活动领域读取 `/data/YYYY-MM-DD-<domain>.json`。单个请求失败、非 JSON 或结构无效时跳过该文件，不影响其他文件。
3. 每篇文章保留所属领域。用于排序的有效日期回退链固定为：`article.published_date → article.date → payload.date → 请求日期`；每一级只接受有效的 `YYYY-MM-DD`。
4. 跨日期按 `领域 + 规范化 URL` 去重，保留有效排序日期最新的记录；无 URL 时按 `领域 + 标题` 去重。这样同一论文仍可同时属于不同领域。日期相同时保留首次遇到的记录，确保稳定。
5. 合并后的文章按有效排序日期降序排列；日期相同时保持稳定顺序。
6. 每个领域使用按日期从新到旧遇到的第一个有效 Digest。有效 Digest 必须是非数组对象且至少包含一个字段；缺失、`null`、数组、空对象或其他类型均视为无效，并回退到更早的有效 Digest。

`/api/dates` 请求失败时显示通用数据不可用错误；返回空日期列表时显示无数据状态。日期列表存在但所有数据文件均不可用时同样显示通用数据不可用错误。

## 界面

- 删除侧栏日期输入框及 Saved 的日期提示块。
- 标题下方不再显示单日日期，普通视图显示 `Newest first`，收藏视图保留收藏数量。
- 无数据错误改为不依赖具体日期的提示。
- 领域筛选、搜索、收藏、卡片与 Digest 样式保持不变。

## 边界与验证

- 不修改后端数据格式、每日抓取、历史 JSON 或 `/api/dates`。
- 收藏列表继续按 `saved_at` 从新到旧排列。
- 为纯时间线辅助函数添加聚焦行为测试，覆盖日期回退链、非法日期、降序与同日稳定顺序、跨日期去重和每领域 Digest 回退。
- 添加页面契约测试，确认日期输入和 `currentDate` 状态已移除，覆盖 `/api/dates` 失败、空列表、单文件失败隔离和全文件失败状态；确认收藏仍按 `saved_at` 降序。
- 运行完整单元测试与 JSX 静态解析。
